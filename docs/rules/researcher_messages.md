# Researcher messages — plain language (M-20261110-018)

Everything the researcher reads (replies, status notes, approval/question cards) is plain Greek for a non-insider.
- ≤ 8 lines. Say what happened, what it means, what is needed from them (if anything).
- No run ids, job/message ids, entry/attempt, file paths, hashes, spec/envelope/admission/freeze jargon. Explain a term in a few words or drop it.
- At most ONE pointer to files: «καρτέλα 📁 Αρχεία» (+ the path to type there) when files matter.
- Technical detail (run lists, worker notes, launch counts) goes to `.lab/technical.log` and docs, never into the thread.
- The dispatcher already does this for worker notes, batch ends and launches (restart needed to apply, J449).

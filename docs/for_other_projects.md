# Tools and ideas for future projects

Tools and ideas for future projects that replicate the QRL-Lab core (coordinator + agents + dashboard). Not used in QRL-Lab.

Source: evaluation of 2026-10-20, see `docs/extensions_eval_2026-10-20.md`. Facts verified on that date; stars and dates may have changed.

## Perplexity API / MCP server
- What: web search and cited answers as MCP tools (`perplexity_search`, `perplexity_ask`, `perplexity_research`, `perplexity_reason`).
- Useful when: a project has an API budget and wants fast exploratory research or fact lookup; always re-open sources before citing.
- Install: `claude mcp add perplexity --env PERPLEXITY_API_KEY=... -- npx -y @perplexity-ai/mcp-server` (remote HTTP variant in the README).
- Cost/keys: API key and prepaid balance required; Search API $5 per 1,000 requests ($1 Fast Search); Pro subscribers reportedly get $5 monthly API credit (secondary sources).
- Sources: https://github.com/perplexityai/modelcontextprotocol · https://docs.perplexity.ai/docs/getting-started/pricing

## HyperFrames (HeyGen)
- What: Apache-2.0 framework that renders HTML/CSS/animations to deterministic MP4; Claude Code plugin and skills.
- Useful when: a project needs demo videos, animated explainers, or conference talk videos generated by an agent from code.
- Install: `claude plugin marketplace add heygen-com/hyperframes` then `claude plugin install hyperframes@hyperframes`; or `npx hyperframes init my-video`. Needs Node.js 22+ and FFmpeg.
- Cost/keys: local use free; the hosted HeyGen connector spends HeyGen credits.
- Sources: https://github.com/heygen-com/hyperframes · https://github.com/heygen-com/hyperframes/releases

## Claude in Chrome
- What: Anthropic's Chrome extension driven by Claude Code (`claude --chrome`), working inside the user's logged-in browser.
- Useful when: Claude Code runs on a desktop with a GUI browser and the task needs authenticated web apps or live UI debugging.
- Install: install the extension from the Chrome Web Store, then `claude --chrome` or `/chrome`. Needs a Claude Pro/Max/Team/Enterprise login (not an API key).
- Cost/keys: included with the Anthropic plan per the docs; no separate key.
- Source: https://code.claude.com/docs/en/chrome

## Chrome DevTools MCP (Google)
- What: MCP server for inspecting and controlling Chrome: DOM, console, network, performance traces.
- Useful when: debugging a web front-end where console/network/performance data matter and puppeteer scripts are not enough.
- Install: `claude mcp add chrome-devtools -- npx -y chrome-devtools-mcp@latest` plus `--no-usage-statistics --no-performance-crux` to disable telemetry.
- Cost/keys: free, Apache-2.0, no key; telemetry on by default.
- Source: https://github.com/ChromeDevTools/chrome-devtools-mcp

## Playwright MCP (Microsoft)
- What: MCP server giving agents browser control through accessibility snapshots.
- Useful when: an agent must explore or test web UIs interactively, with no existing test scripts.
- Install: `claude mcp add playwright npx @playwright/mcp@latest` (add `--headless` on servers).
- Cost/keys: free, Apache-2.0, no key. README states it is not a security boundary; `browser_run_code_unsafe` is RCE-equivalent.
- Source: https://github.com/microsoft/playwright-mcp

## Firecrawl (API / MCP server)
- What: web search, scrape, crawl as MCP tools; self-hostable.
- Useful when: a project must bulk-collect or monitor many web pages into clean markdown and WebFetch is too limited.
- Install: `env FIRECRAWL_API_KEY=... npx -y firecrawl-mcp`; keyless rate-limited endpoint `https://mcp.firecrawl.dev/v2/mcp`; self-host via `FIRECRAWL_API_URL`.
- Cost/keys: key needed for the cloud API; free plan reported at 1,000 credits per month (verify on the pricing page).
- Source: https://github.com/firecrawl/firecrawl-mcp-server · https://www.firecrawl.dev/pricing

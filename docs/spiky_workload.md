## 2. New workload `poisson_ms_spiky` (poisson_ms is NOT changed; anchor kept)
Same env, reward, state, delay (5), pods 1-20; only the rate path differs. Diurnal (amp 0.4) and AR(1) noise (σ 0.15) are kept; the 2-state burst chain is replaced by an explicit overlay `λ_t = base·diurnal·e^{x_t}·m_t`, `m_t = 1 + Σ events`:
1. **abrupt flash crowds**: Poisson onsets (1/450 per tick), instant jump, amplitude ×LogU(1.8,3.5), plateau LogNormal(median 40 ticks), exponential decay τ=15;
2. **gradual ramps**: 1/600 per tick, linear up 15-60 ticks, plateau 20-80, linear down, extra amplitude U(0.8,1.8);
3. **burst trains (recurring)**: 1/900 per tick, 3-6 pulses every 45±4 ticks, width 12, extra amplitude U(1,2), each pulse dropped w.p. 0.1.
`λ` is clipped at 190 (max capacity is 200; poisson_ms itself exceeds it up to 384, which no policy can serve). `base=48.94` is calibrated so mean offered load = poisson_ms (71.6 req/tick; MC over 200 traces, ids 9 000 000+, `.lab/j291/calib_v1.json`: spiky mean 71.7, tick CV 0.59 vs 0.55, share of ticks >100 req 19% vs 12%, >150 8.3% vs 6.0%).
- Parameters are a-priori design choices stating the shape families (flash crowd / ramp / recurring), NOT fitted to a trace and NOT chosen by agent results; they were fixed before any agent ran on it. The motivation that production serverless load is highly irregular and heavy-tailed is from Shahrad et al., ATC'20 (arXiv 2003.03423, https://www.usenix.org/conference/atc20/presentation/shahrad); I did not verify trigger/burst statistics, so no numeric claim is taken from it.
- What the history can and cannot give: ramps and decay phases are predictable from a short window (slope); abrupt onsets are not (only reactive); the 45-tick pulse period exceeds the 10-tick window, so recurrence is learnable only through the replay/policy, not the window. Whether the LSTM benefits is exactly what the experiment tests; a null result is reportable. Note the recurrent nets reset (h,c) to zero on every forward (`agent_lstm_v2.py:105`), so memory beyond the window does not exist at inference. Events have no carry-in before tick 0 (start-up non-stationarity, same for all arms). Caveat: a new benchmark chosen in response to «Dinos should win» is exploratory; poisson_ms stays the anchor and results are reported on both.
- Splits (disjoint from all earlier ones): val 16000-16019, test13 16500-16519 (locked, single use). Tests: `tuning/tests/test_spiky.py` (8 PASS; determinism, action independence, mean match ±3%, cap, onset instant, ramp slope bound, train recurrence, split lock, hpa_orig), plus existing `test_poisson_ms.py`/`test_pms_harness.py` PASS (poisson_ms unchanged).
